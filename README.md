# Сокращение ссылок

Это веб-приложение для сокращения ссылок, написанное на FastAPI.

## Стек технологий

- Backend: Python 3.13, FastAPI, SQLAlchemy, asyncpg, uv
- Frontend: HTML, CSS, JavaScript
- База данных: PostgreSQL (через SQLAlchemy)
- Веб-сервер: Gunicorn + UvicornWorker
- Контейнеризация: Docker, Docker Compose
- Управление зависимостями: uv (вместо pip)
- Линтинг и форматирование: ruff, black
- Проверка типов: mypy
- Тестирование: pytest
- CI/CD: pre-commit хуки

## Запуск проекта

### Локальный запуск (с uv)

1. Убедитесь, что у вас установлен Python 3.13 и [uv](https://github.com/astral-sh/uv).
2. Установите зависимости:
   ```bash
   make dev
   ```
   Эта команда установит основные и dev-зависимости с помощью `uv`.
3. Настройте pre-commit хуки:
   ```bash
   make install-hooks
   ```
4. Создайте файл `.env` на основе примера (см. ниже) и настройте параметры базы данных.
5. Запустите приложение:
   ```bash
   make
   ```
   Это запустит `uvicorn src.main:app --reload`.

### Запуск через Docker

1. Убедитесь, что у вас установлены Docker и Docker Compose.
2. Запустите все сервисы:
   ```bash
   make docker
   ```
   Эта команда соберет образ и запустит контейнеры.

Приложение будет доступно по адресу http://localhost:8000

## Настройка окружения

Создайте файл `.env` в корне проекта со следующими переменными:

```env
DB_TYPE=...
POSTGRES_USER=...
POSTGRES_PASSWORD=...
POSTGRES_DB=...
POSTGRES_HOST=...
POSTGRES_PORT=5432
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0
```

При запуске в Docker (`docker-compose`) база данных и Redis будут запущены автоматически.

## Использование

1. Откройте фронтенд по адресу http://localhost:8000
2. Введите длинную ссылку в поле ввода
3. Нажмите кнопку "Сократить"
4. Получите короткую ссылку, которую можно скопировать
5. Перейдите по короткой ссылке, чтобы перенаправиться на оригинальный URL

Также можно напрямую перейти по http://localhost:8000/short_url для отображения формы сокращения.

## API

- `POST /short_url` - создание короткой ссылки
  - Тело запроса: `{"long_url": "https://example.com"}`
  - Ответ: `{"short_url": "/abc123"}`
- `GET /{slug}` - редирект по короткой ссылке

## Разработка

### Команды Makefile

- `make dev` - установка зависимостей
- `make install-hooks` - установка pre-commit хуков
- `make lint` - проверка кода линтером (ruff)
- `make fix` - автоматическое исправление и форматирование кода (black + ruff + mypy)
- `make typecheck` - проверка типов (mypy)
- `make test` - запуск тестов
- `make coverage` - запуск тестов с отчетом о покрытии
- `make check` - полная проверка (линтинг, типы, тесты) - аналог CI
- `make pre-commit` - запуск всех pre-commit хуков вручную
- `make all` - `make fix check`
- `make clean` - очистка проекта
- `make docker-build` - сборка Docker образа
- `make docker-run` - запуск приложения в Docker
- `make docker` - `make docker-build docker-run`

### Инструменты

Проект использует современные инструменты для поддержания качества кода:

- **uv** - быстрый менеджер зависимостей, заменяет pip и venv.
- **ruff** - сверхбыстрый линтер и форматировщик (альтернатива flake8 + isort + других).
- **black** - форматировщик кода, "незлобивый парень".
- **mypy** - проверка типов в Python.
- **pre-commit** - хуки для запуска линтеров перед коммитом.

Настройки всех этих инструментов находятся в `pyproject.toml`.

## Особенности реализации

- **Асинхронность**: приложение использует асинхронные возможности FastAPI и SQLAlchemy.
- **Конфигурация через переменные окружения**: все параметры подключения к базе данных вынесены в `.env`.
- **Docker-нативность**: приложение легко контейнеризируется, все сервисы (бэкенд, база данных, Redis) описаны в `docker-compose.yaml`.
- **Healthcheck**: в Dockerfile добавлен healthcheck для мониторинга состояния приложения.
- **Gunicorn + Uvicorn**: производственное развертывание с использованием веб-сервера и асинхронного воркера.
