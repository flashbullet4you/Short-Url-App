# Сокращение ссылок

Это веб-приложение для сокращения ссылок, написанное на FastAPI.

## Стек технологий

- Backend: Python, FastAPI, SQLAlchemy
- Frontend: HTML, CSS, JavaScript
- База данных: SQLite (через SQLAlchemy)

## Структура проекта

```
├── src/
│   ├── main.py          # Точка входа приложения
│   ├── service.py       # Логика приложения
│   ├── shortener.py     # Генерация коротких ссылок
│   └── database/
│       ├── db.py        # Конфигурация базы данных
│       ├── models.py    # Модели базы данных
│       └── crud.py      # Операции с базой данных
├── tests/               # Тесты
├── frontend/            # Фронтенд-часть
│   ├── index.html       # Главная страница
│   ├── css/
│   │   └── style.css    # Стили
│   └── js/
│       └── main.js      # Логика фронтенда
├── docker-compose.yaml  # Docker Compose конфигурация
└── pyproject.toml       # Зависимости и настройки
```

## Запуск проекта

1. Убедитесь, что у вас установлен Python 3.11+
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Linux/Mac
   # или
   .venv\Scripts\activate    # Windows
   pip install -r requirements.txt
   ```
3. Запустите сервер:
   ```bash
   uvicorn src.main:app --reload
   ```
4. Откройте фронтенд по адресу `http://localhost:8000/frontend/index.html`

## Использование

1. Введите длинную ссылку в поле ввода
2. Нажмите кнопку "Сократить"
3. Получите короткую ссылку, которую можно скопировать
4. Перейдите по короткой ссылке, чтобы перенаправиться на оригинальный URL

## API

- `POST /short_url` - создание короткой ссылки
- `GET /{slug}` - редирект по короткой ссылке
